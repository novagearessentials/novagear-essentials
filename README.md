# NovaGear Essentials Website

A lightweight, mobile-friendly affiliate product-discovery website for NovaGear Essentials.

## Before publishing
1. Replace the placeholder product links in `index.html` with your approved affiliate URLs.
2. Add your real social media links when ready.
3. Add a contact email.
4. Keep the affiliate disclosure visible.
5. Do not claim that NovaGear ships products; retailers handle fulfillment and shipping.

## Free publishing with GitHub Pages
1. Create a GitHub repository, e.g. `novagear-essentials`.
2. Upload `index.html` and `styles.css`.
3. In the repository, open Settings → Pages.
4. Choose the `main` branch and root folder.
5. Save. GitHub will provide the public website URL.
6. Use that exact URL when an affiliate application asks for your website.

## Important
This site is a starter affiliate website. It does not make you an Amazon Associate automatically. Apply to Amazon and other affiliate programs separately and only use affiliate links after approval.
